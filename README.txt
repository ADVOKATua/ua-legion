UA LEGION ETS2 — компактна сторінка інформації

ВМІСТ
- ets2-info.html — оновлена інформаційна сторінка
- ets2-info-page.css — компактніші відступи й картки, без нумерації розділів
- assets/ets2/ua-legion-ets2-bg.mp4 — фонове відео
- assets/ets2/ua-legion-ets2-poster.jpg — постер для відео/мобільних пристроїв
- apply-ets2-cleanup.ps1 — допоміжний скрипт для локальної копії репозиторію

ЩО ЗМІНЕНО
- Прибрано пункт «Головна ETS2» з бокового меню інформаційної сторінки.
- Логотип/назва ETS2 веде на ets2-info.html замість ets2.html.
- Картка ETS2 на games.html веде на ets2-info.html.
- Файл ets2.html видаляється з репозиторію; окремої сторінки за цією адресою більше не буде.
- Прибрано нумерацію заголовків розділів і карток принципів.
- Зменшено відступи та висоту карток для компактнішого вигляду.

ВСТАНОВЛЕННЯ
1. Розпакуйте архів у корінь локальної копії репозиторію ADVOKATua/ua-legion, дозволивши замінити ets2-info.html та ets2-info-page.css.
2. Переконайтеся, що assets/ets2/ лежить у корені репозиторію саме за цим шляхом.
3. Відкрийте PowerShell у корені репозиторію та запустіть .\apply-ets2-cleanup.ps1. Скрипт змінить посилання в games.html на ets2-info.html, прибере посилання «Головна ETS2» з інших HTML-файлів, перенаправить решту посилань з ets2.html на ets2-info.html та видалить ets2.html.
4. Перегляньте зміни, потім виконайте git add -A, git commit -m "Compact ETS2 info and remove ETS2 home page", git push.

Якщо не користуєтесь локальним Git, завантажте ets2-info.html і ets2-info-page.css вручну через GitHub, видаліть ets2.html через меню файлу на GitHub, а з інших ets2-*.html приберіть посилання «🏠 Головна ETS2» та замініть href логотипу з ets2.html на ets2-info.html.
